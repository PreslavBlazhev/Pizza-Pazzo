# Тест преди подаване в Google Play

Последният преглед преди „Roll out“. Минава се **на истинско устройство, с
инсталиран release APK** (`android-app/dist/pizza-pazzo-1.0.1-v2.apk`), срещу
**production** сайта — не срещу `npm run dev`.

Ако нещо тук падне, то пада и пред рецензента.

---

## 0. Какво вече е проверено автоматично

Тези не ги правѝ на ръка — пусни ги и гледай изхода:

```bash
npm run type-check          # tsc
npm run lint                # eslint
npm run check:i18n          # bg/en ключовете в синхрон
npm run smoke               # меню + ценообразуване (не пише в базата)
npm run smoke:deletion      # изтриване на профил: какво остава и какво не
npm run build               # production build

cd android-app
gradlew.bat testDebugUnitTest lintDebug   # 77 unit теста + Android lint
```

Проверено на живо на 25.09.2026 (`curl`, без сесия):

| Адрес | Очаквано | Резултат |
|---|---|---|
| `/app-privacy` | 200, реално съдържание | ✅ 200 |
| `/account-deletion` | 200, реално съдържание | ✅ 200 |
| `/en/app-privacy` | 200 | ✅ 200 |
| `/en/account-deletion` | 200 | ✅ 200 |
| `/admin` без сесия | 307 → `/auth/login` | ✅ 307 |

> ⚠️ Проверѝ ги пак **след деплоя** на новите текстове — горното е стар билд.

## 3. Размери, добавки и цени

| # | Стъпка | Очаквано |
|---|---|---|
| 3.1 | Пица с два размера | Цената се сменя със размера |
| 3.2 | Добави 2–3 добавки | Всяка добавка вдига цената с точната си стойност |
| 3.3 | Количество 2 | Добавките се умножават по бройките |
| 3.4 | Тесто/сос | Влизат в сумата, не са безплатни по невнимание |
| 3.5 | Количка vs. чекаут vs. бележка | **И трите показват една и съща крайна сума** |
| 3.6 | Доставка | Таксата е добавена отделно и се вижда преди потвърждение |

> `npm run smoke` проверява същото правило за ценообразуване върху цялото меню.
> Ръчният тест е за това, което скриптът не вижда: че и екранът го показва така.

## 6. История и изтриване на профил

| # | Стъпка | Очаквано |

| 6.1 | Профил → Моите поръчки | Всички поръчки на този профил |
| 6.2 | Профил → Изтриване на профила | Текстът обяснява какво остава и какво се заличава |
| 6.3 | Потвърди с парола | Изход от профила, страница „Профилът е изтрит“ |

| 6.5 | В админа: старата поръчка | Показва „Профилът е изтрит по искане на клиента“; **няма** име, телефон, имейл и адрес |

> Точно това проверява и `npm run smoke:deletion`, включително случая с поръчка,
> която още пътува: тя пази адреса си до доставяне и се заличава веднага след.

## 8. Преди да натиснеш „Roll out“

- [ ] `versionCode` е по-голям от последния качен (сега: **2**, versionName 1.0.1)
- [ ] Качваш `.aab`, не `.apk`
- [ ] Демо акаунтите съществуват в **production** базата
      (`node scripts/create-review-accounts.mjs` в Render Shell) и паролите са
      в „App access“
- [ ] Екранните снимки са от истинското приложение
- [ ] Data safety е попълнен по таблицата в `android-app/PLAY_STORE.md` т. 7
- [ ] Въпросът за алкохол в IARC е отговорен според реалното меню
- [ ] Keystore-ът е архивиран на две места извън компютъра
