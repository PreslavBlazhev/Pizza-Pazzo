# Pizza Pazzo — Printing Plan

## Версия 1 — Browser print (текущ план)
Първата версия използва **обикновена браузър print страница**, оптимизирана за
**80mm термален принтер**. Няма нужда от драйвери или локален софтуер — печата се
директно от браузъра през стандартния диалог за печат (Ctrl/Cmd + P).

### Как работи
- Страница: `app/admin/orders/[id]/print/page.tsx`
- Компонент: `components/admin/PrintTicket.tsx`
- Шаблон (текст): `lib/printer/ticket-template.ts`
- Настройки: `lib/printer/print-config.ts` (ширина 80mm, ~42 символа на ред)
- Print стилове: `.print-ticket` / `.no-print` в `app/globals.css`

### Съдържание на бележката
- Заглавие (Pizza Pazzo) и номер на поръчка
- Продукти с количество, опции и цени
- Обща сума
- Адрес за доставка / телефон
- (Опционално) алергени

### Настройка на принтера
- Размер на хартията: 80mm (roll)
- Полета: 0
- Мащаб: 100%
- Изключване на header/footer на браузъра

## Версия 2+ (бъдеще)
- Автоматичен печат при приемане на поръчка
- Директен печат към мрежов принтер или локален print agent
- ESC/POS команди за по-добър контрол
- Endpoint `app/api/print/route.ts` е подготвен като заготовка за това.
